# Compétences Claude d'Emmanuel

`install-skills.py` clone les dépôts de compétences (humanizer, hyperframes, superpowers,
impeccable, instagram-agent-skill, hiring-panel, last30days, etc.) et les copie dans
`~/.claude/skills`. Le script de démarrage de l'environnement cloud le lance à chaque
nouvelle session, routines comprises. Pour en ajouter une : ajouter `owner/repo` à `REPOS`.
